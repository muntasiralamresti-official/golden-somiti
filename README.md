# 🌟 গোল্ডেন সমিতি (Golden Somiti) — ফান্ড ও সদস্য ব্যবস্থাপনা সফটওয়্যার

একটি আধুনিক, মোবাইল-ফার্স্ট ও নিরাপদ আর্থিক হিসাব-নিকাশ এবং সদস্য লেজার ড্যাশবোর্ড।

---

## 🚀 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **🏠 হোম ড্যাশবোর্ড:**
   - মোট কিস্তি আদায়, সমিতির মোট ব্যয় ও বর্তমান ব্যাংকে/হাতে নগদ ফান্ড স্থিতি।
   - বার্ষিক আর্থিক অগ্রগতির গ্রাফ ও রিয়েল-টাইম পরিসংখ্যান।
   - দ্রুত ১-ট্যাপ অ্যাকশন (জমা নিন, খরচ লিখুন, নতুন সদস্য, পিডিএফ ডাউনলোড)।

2. **💰 জমা-খরচ ক্যাশবুক:**
   - **জমার খতিয়ান:** কিস্তি আদায়, মাসভিত্তিক ফিল্টার, রশিদ নম্বর ও পেমেন্ট মাধ্যম (নগদ/বিকাশ/ব্যাংক)।
   - **খরচ ও সমবণ্টন:** খরচের ভাউচার, ক্যাটাগরি এবং সকল সক্রিয় সদস্যের মাঝে খরচের স্বয়ংক্রিয় সমান বণ্টন।

3. **👥 সদস্য ও প্রোফাইল লেজার:**
   - সদস্য তালিকা, নাম/কোড/মোবাইল দিয়ে দ্রুত সার্চ।
   - বকেয়া ও পরিশোধিত ফিল্টার।
   - প্রতিটি সদস্যের বর্তমান ও বিগত সব বছরের জমার হিসাব, বকেয়া, খরচের অংশ এবং নিট ফান্ড স্থিতি।
   - সদস্যের নিজস্ব একক বাংলা PDF স্টেটমেন্ট।

4. **📑 পূর্ণাঙ্গ বাংলা অডিট PDF রিপোর্ট:**
   - সমিতি অডিট ও সাধারণ সভার জন্য ১-ক্লিকে বাংলা ফন্টে হাই-রেজোলিউশন রেজুলেশন ও আর্থিক বিবরণী ডাউনলোড।

5. **⚙️ সেটিংস ও ব্যাকআপ নিরাপত্তা:**
   - 📱 মোবাইল ডিসপ্লেতে পড়ার সুবিধার্থে ফন্ট সাইজ নিয়ন্ত্রণ (ছোট, স্বাভাবিক, বড়, খুব বড়)।
   - ৳ বাৎসরিক কিস্তির হার ও টার্গেট সেটআপ।
   - 💾 ১-ক্লিকে ডাটাবেজের সম্পূর্ণ JSON ব্যাকআপ ডাউনলোড ও যে কোনো সময় রিস্টোর।
   - 📲 PWA মোবাইল অ্যাপ ইনস্টলেশন ও অটো ইমেজ অপটিমাইজার (WebP কম্প্রেশন)।

## 🛠️ প্রযুক্তি (Tech Stack)

- **Frontend:** React 19, Vite, Tailwind CSS v4, Lucide Icons, html2canvas, jsPDF
- **Backend:** Node.js, Express, Mongoose
- **Database:** MongoDB Atlas (Cloud)
- **Deployment:** Vercel (Serverless Full-Stack)

---

## 🌐 Vercel-এ লাইভ করার সহজ নিয়ম

1. **GitHub-এ আপলোড করুন:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Golden Somiti"
   git branch -M main
   git remote add origin <your-github-repo-url>
   git push -u origin main
   ```

2. **Vercel-এ ডিপ্লয় করুন:**
   - [vercel.com](https://vercel.com)-এ যান এবং `Add New Project` সিলেক্ট করে আপনার GitHub রিপোজিটরিটি সিলেক্ট করুন।
   - **Environment Variables** সেকশনে নিচের ভেরিয়েবলটি যুক্ত করুন:
     - **Key:** `MONGO_URI`
     - **Value:** `আপনার MongoDB Atlas Connection String`
   - `Deploy` বাটনে ক্লিক করুন। ২ মিনিটের মধ্যে আপনার সফটওয়্যারটি বিশ্বব্যাপী লাইভ হয়ে যাবে!

## 💻 লোকাল মেশিনে রান করার নিয়ম

1. **ডিপেন্ডেন্সি ইনস্টল:**
   ```bash
   npm install --prefix backend
   npm install --prefix frontend
   ```

2. **প্রজেক্ট চালু:**
   ```bash
   npm run dev
   ```
   - ব্রাউজারে খুলুন: `http://localhost:5173`
